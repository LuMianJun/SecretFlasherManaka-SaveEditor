# SecretFlasherManaka 存檔編輯器

適用於 **SecretFlasherManaka** 的 Windows 獨立存檔編輯工具。

直接打開遊戲的 `.sd` 存檔，按分類查看和修改內容，再保存為遊戲使用的加密格式。無需安裝 MOD，也不依賴 BepInEx；所有存檔處理均在本地完成。

下載與版本記錄：[GitHub Releases](https://github.com/LuMianJun/SecretFlasherManaka-SaveEditor/releases)。

## 功能

- 按分類編輯 RP、成長、任務歷史、物品、裝備、技能、強化、場景解鎖和歷史統計。
- 預設進入“常用”，集中展示可用 RP、露出經驗、物品、最大被發現容忍次數、成人玩具強化和服飾部件強化；也可從原分類編輯同一份數據。
- 已收錄的物品、裝備、強化效果等按當前介面語言顯示原版名稱；振動模式等枚舉按實際含義選擇。
- 原版任務記錄顯示“【場景】任務名稱”，可按場景名搜索；無人機分地圖記錄同樣標明場景，匯總次數保留跨地圖含義。
- 技能等級按各技能的原版上限選擇，直接輸入原始數值時也會檢查範圍；已有異常值不會自動改寫。
- 難度提供原版開放的“簡易”和“普通”兩檔；晝夜時間顯示為“白天”或“夜晚”。
- 支持搜索、撤銷、改動清單，以及還原到最近打開或保存時的內容。
- 角色外觀、預設、快捷操作、模式設定、教程已讀記錄和部分詳細記錄預設收起，需要時展開編輯。
- 預設隱藏本次任務進度、待結算收益、即時狀態、場景現場數據、系統槽位摘要、舊私服強化表和輔助提示標記；分類計數和搜索也不包含這些欄位。
- 技能、強化、服飾等名稱表中未收錄的編號預設隱藏，原始數據仍保留；未知任務記錄繼續顯示，並明確註明存檔未記錄名稱。
- 提供完整原始結構視圖，支持編輯未知欄位，以及新增、刪除對象或列表條目。
- 支持保存、另存為和存檔槽位 ID 校驗。
- 保存手動槽位時，同步同目錄 `s.sd` 中對應槽位的等級、保存時間、難度和遊玩時間，修復讀檔列表顯示舊值或預設值的問題。
- 說明欄按需提示讀檔覆蓋、條件生效和未知名稱等會影響修改結果的資訊。

工具使用 **Tauri + Rust + TypeScript + CSS**，重用系統 WebView2，前端與名稱數據嵌入單個 EXE，無需 Python。

## 介面語言

右上角的地球圖標按鈕可切換簡體中文、繁體中文、English、日本語、한국어，與原遊戲五個語言選項一致。尚未設定語言時，介面預設中文並自動彈出語言選擇視窗，每個選項均顯示自己的語言名稱。明確選擇後會記住設定，以後啟動不再自動彈出。選擇會保存在本機編輯器設定中，切換時保留已打開的存檔、未暫存輸入和當前瀏覽狀態；不會修改存檔裡的遊戲語言或其他欄位。

物品、技能、服飾、任務、場景、成就等使用原版字典的對應語言列。任務的地點、距離和成就條件按原版主表及名稱格式化規則填入，不從中文名稱反譯。部分原版舊記錄直接使用日文常量且沒有翻譯鍵，這些記錄保留原始字面名稱。編輯器自己的操作、欄位說明和修復提示另行翻譯。

名稱來源與更新方法見 [多語言與原版名稱](docs/多语言与原版名称.md)（詳細文件為簡體中文）。

## 使用方法

運行 `SecretFlasherManakaSaveEditor.exe`，點擊右上角的“打開存檔”。打開和另存為預設定位到遊戲存檔目錄：

```text
%USERPROFILE%\AppData\LocalLow\SheableSoft\SecretFlasherManaka\SaveData
```

選擇欄位，在右側修改後點擊“暫存修改”。暫存只修改工具中的數據；點擊“保存”時，也會提交當前欄位尚未暫存的輸入。

- **保存**：確認文件、存檔 ID 和修改數量後，覆蓋當前文件。
- **另存為**：預設在遊戲存檔目錄中使用最小的空閑槽位文件名；系統存檔預設使用 `s.sd`。選擇目標位置後寫入，已有文件由文件對話框確認覆蓋。保存成功後，新位置成為當前文件。
- **快捷鍵**：`Ctrl+S` 保存，`Ctrl+Shift+S` 另存為。

保存會覆蓋選定文件，不自動生成備份，請自行保留需要的原始存檔。

## 存檔與保存規則

| 文件 | 內容與校驗 |
| --- | --- |
| `0.sd`～`19.sd` | 手動存檔，內部槽位 ID 必須與文件名編號一致。 |
| `s.sd` | 系統存檔，包含設定、教程和存檔列表，不使用進度槽位 ID。 |

保存到 `0.sd`～`19.sd` 時，工具按目標文件名自動設定內部槽位 ID，無需手動編輯。覆蓋已有文件仍會校驗存檔類型與目標槽位；取消或保存失敗不會改變當前文檔的槽位 ID。另存為時若 20 個槽位均已占用，則預設保留當前文件名，由你選擇保存位置並確認覆蓋。

若目標目錄存在系統存檔 `s.sd`，保存同時更新目標槽位的列表摘要：等級根據露出經驗計算，難度與遊玩時間取自進度存檔，保存時間使用本地當前時間。確認框會列出同步目標；無改動時也可以重新保存以修復摘要。其他槽位、全局設定和教程記錄保留。獨立副本旁沒有 `s.sd` 時不創建系統存檔；非槽位文件名也不觸發同步。遊戲已打開時，列表可能仍使用內存中的舊摘要，需要重新啟動遊戲讀取。

工具保留原始存檔結構，僅替換編輯範圍，保留未修改欄位、小數精度、原版類型資訊和未知內容。保存時核對加密、解密後的內容，在目標目錄寫入臨時文件並驗證，再替換目標文件。

介面隱藏不等于刪除：運行時欄位仍保留在存檔中，保存不會因其未展示而清零或移除；完整原始片段也保留這些內容。可用 RP、累計 RP 和歷史記錄是獨立欄位，工具不會自動同步。修改後的欄位組合是否符合遊戲運行邏輯，仍取決于原版規則。

原版任務名稱來自工具內置的原版名稱數據。自定義任務的名稱通常不在存檔中，工具不會猜測或寫死名稱，也不要求安裝外部插件；無法識別時顯示“未知任務（編號…，存檔未記錄名稱）”。

詳細欄位範圍、讀檔覆蓋行為與保存時機見 [存檔類型與欄位作用](docs/存档类型与字段作用.md)（詳細文件為簡體中文）。

## 存檔修復（首版）

打開進度存檔後點擊“修復存檔”，預覽“清理擴展數據＋補全原版必要數據”的清單，再點擊“應用修復”。這一步只修改工具內的數據，可整批撤銷；首次保存強制另存到其他文件，原文件不覆蓋。

修復依據工具內置的當前已核查原版欄位、枚舉和主表編號，不加載任何 MOD DLL，也不需要逐個適配 MOD。它會移除進度文件中的擴展欄位，以及物品、技能、任務、服飾、預設等已核查編號表中的擴展記錄；同步處理服飾所有權、選項、強化、鎖定和全部預設中的關聯引用。原版枚舉裡的舊編號和哨兵值會保留，不按介面有沒有名稱判斷。

缺失或結構異常的原版數據按已核查預設規則補齊，包括強化的 3 個效果槽、4 個鎖定開關、20 個服裝/外觀預設等。合法欄位的原始數字文本保留，已有 RP、原版任務成績和裝備記錄不主動重算。丟失的真實成績只能從備份恢復；補預設值不等于恢復歷史進度。

首版支持能夠解密、解析且具有可識別 GameStateData 類型頭的進度存檔；缺失/異常的槽位 ID 可按手動槽位文件名補全。暫不修復系統存檔 s.sd、文件截斷、加密損壞，也不保證修復所有遊戲運行錯誤。新版本原版欄位可能被舊規則視為擴展，使用前核對預覽。這個模式會刪除其他 MOD 的擴展任務等進度；普通打開和保存不會自動清理。

## 從源碼構建

需要 Windows x64、Rust stable、Node.js 18+、MSVC C++ Build Tools 和 Windows SDK。運行工具需要 Microsoft Edge WebView2 Runtime。

在 Visual Studio 開發者 PowerShell 中執行：

```powershell
cd tauri
npm ci
npm --prefix ui ci
npm run build
```

生成的程序位於：

```text
tauri/src-tauri/target/release/SecretFlasherManakaSaveEditor.exe
```

開發模式使用 `npm run dev`。項目另提供根目錄的 `build.ps1` 打包腳本，預設查找 Visual Studio 2022 Build Tools 和 Windows SDK 的標準安裝位置。

## 項目結構

```text
docs/               欄位適用範圍與保存時機說明
tauri/
  ui/             TypeScript 介面、樣式與多語言名稱數據
  src-tauri/      Rust 存檔解析、加解密、校驗與桌面入口
  metadata.json   欄位分類元數據
format_config.json  存檔格式配置
build.ps1           本地打包腳本
```
