# SecretFlasherManaka 存档编辑器

适用于 **SecretFlasherManaka** 的 Windows 独立存档编辑工具。

直接打开游戏的 `.sd` 存档，按分类查看和修改内容，再保存为游戏使用的加密格式。无需安装 MOD，也不依赖 BepInEx；所有存档处理均在本地完成。

下载与版本记录：[GitHub Releases](https://github.com/LuMianJun/SecretFlasherManaka-SaveEditor/releases)。

## 功能

- 按分类编辑 RP、成长、任务历史、物品、装备、技能、强化、场景解锁和历史统计。
- 默认进入“常用”，集中展示可用 RP、露出经验、物品、最大被发现容忍次数、成人玩具强化和服饰部件强化；也可从原分类编辑同一份数据。
- 已收录的物品、装备、强化效果等按当前界面语言显示原版名称；振动模式等枚举按实际含义选择。
- 原版任务记录显示“【场景】任务名称”，可按场景名搜索；无人机分地图记录同样标明场景，汇总次数保留跨地图含义。
- 技能等级按各技能的原版上限选择，直接输入原始数值时也会检查范围；已有异常值不会自动改写。
- 难度提供原版开放的“简单”和“普通”两档；昼夜时间显示为“白天”或“夜晚”。
- 支持搜索、撤销、改动清单，以及还原到最近打开或保存时的内容。
- 角色外观、预设、快捷操作、模式设置、教程已读记录和部分详细记录默认收起，需要时展开编辑。
- 默认隐藏本次任务进度、待结算收益、即时状态、场景现场数据、系统槽位摘要、旧私服强化表和辅助提示标记；分类计数和搜索也不包含这些字段。
- 技能、强化、服饰等名称表中未收录的编号默认隐藏，原始数据仍保留；未知任务记录继续显示，并明确注明存档未记录名称。
- 提供完整原始结构视图，支持编辑未知字段，以及新增、删除对象或列表条目。
- 支持保存、另存为和存档槽位 ID 校验。
- 保存手动槽位时，同步同目录 `s.sd` 中对应槽位的等级、保存时间、难度和游玩时间，修复读档列表显示旧值或默认值的问题。
- 说明栏按需提示读档覆盖、条件生效和未知名称等会影响修改结果的信息。

工具使用 **Tauri + Rust + TypeScript + CSS**，复用系统 WebView2，前端与名称数据嵌入单个 EXE，无需 Python。

## 界面语言

右上角的地球图标按钮可切换简体中文、繁体中文、English、日本語、한국어，与原游戏五个语言选项一致。尚未设置语言时，界面默认中文并自动弹出语言选择窗口，每个选项均显示自己的语言名称。明确选择后会记住设置，以后启动不再自动弹出。选择会保存在本机编辑器设置中，切换时保留已打开的存档、未暂存输入和当前浏览状态；不会修改存档里的游戏语言或其他字段。

物品、技能、服饰、任务、场景、成就等使用原版字典的对应语言列。任务的地点、距离和成就条件按原版主表及名称格式化规则填入，不从中文名称反译。部分原版旧记录直接使用日文常量且没有翻译键，这些记录保留原始字面名称。编辑器自己的操作、字段说明和修复提示另行翻译。

名称来源与更新方法见 [多语言与原版名称](docs/多语言与原版名称.md)。

## 使用方法

运行 `SecretFlasherManakaSaveEditor.exe`，点击右上角的“打开存档”。打开和另存为默认定位到游戏存档目录：

```text
%USERPROFILE%\AppData\LocalLow\SheableSoft\SecretFlasherManaka\SaveData
```

选择字段，在右侧修改后点击“暂存修改”。暂存只修改工具中的数据；点击“保存”时，也会提交当前字段尚未暂存的输入。

- **保存**：确认文件、存档 ID 和修改数量后，覆盖当前文件。
- **另存为**：默认在游戏存档目录中使用最小的空闲槽位文件名；系统存档默认使用 `s.sd`。选择目标位置后写入，已有文件由文件对话框确认覆盖。保存成功后，新位置成为当前文件。
- **快捷键**：`Ctrl+S` 保存，`Ctrl+Shift+S` 另存为。

保存会覆盖选定文件，不自动生成备份，请自行保留需要的原始存档。

## 存档与保存规则

| 文件 | 内容与校验 |
| --- | --- |
| `0.sd`～`19.sd` | 手动存档，内部槽位 ID 必须与文件名编号一致。 |
| `s.sd` | 系统存档，包含设置、教程和存档列表，不使用进度槽位 ID。 |

保存到 `0.sd`～`19.sd` 时，工具按目标文件名自动设置内部槽位 ID，无需手动编辑。覆盖已有文件仍会校验存档类型与目标槽位；取消或保存失败不会改变当前文档的槽位 ID。另存为时若 20 个槽位均已占用，则默认保留当前文件名，由你选择保存位置并确认覆盖。

若目标目录存在系统存档 `s.sd`，保存同时更新目标槽位的列表摘要：等级根据露出经验计算，难度与游玩时间取自进度存档，保存时间使用本地当前时间。确认框会列出同步目标；无改动时也可以重新保存以修复摘要。其他槽位、全局设置和教程记录保留。独立副本旁没有 `s.sd` 时不创建系统存档；非槽位文件名也不触发同步。游戏已打开时，列表可能仍使用内存中的旧摘要，需要重新启动游戏读取。

工具保留原始存档结构，仅替换编辑范围，保留未修改字段、小数精度、原版类型信息和未知内容。保存时核对加密、解密后的内容，在目标目录写入临时文件并验证，再替换目标文件。

界面隐藏不等于删除：运行时字段仍保留在存档中，保存不会因其未展示而清零或移除；完整原始片段也保留这些内容。可用 RP、累计 RP 和历史记录是独立字段，工具不会自动同步。修改后的字段组合是否符合游戏运行逻辑，仍取决于原版规则。

原版任务名称来自工具内置的原版名称数据。自定义任务的名称通常不在存档中，工具不会猜测或写死名称，也不要求安装外部插件；无法识别时显示“未知任务（编号…，存档未记录名称）”。

详细字段范围、读档覆盖行为与保存时机见 [存档类型与字段作用](docs/存档类型与字段作用.md)。

## 存档修复（首版）

打开进度存档后点击“修复存档”，预览“清理扩展数据＋补全原版必要数据”的清单，再点击“应用修复”。这一步只修改工具内的数据，可整批撤销；首次保存强制另存到其他文件，原文件不覆盖。

修复依据工具内置的当前已核查原版字段、枚举和主表编号，不加载任何 MOD DLL，也不需要逐个适配 MOD。它会移除进度文件中的扩展字段，以及物品、技能、任务、服饰、预设等已核查编号表中的扩展记录；同步处理服饰所有权、选项、强化、锁定和全部预设中的关联引用。原版枚举里的旧编号和哨兵值会保留，不按界面有没有名称判断。

缺失或结构异常的原版数据按已核查默认规则补齐，包括强化的 3 个效果槽、4 个锁定开关、20 个服装/外观预设等。合法字段的原始数字文本保留，已有 RP、原版任务成绩和装备记录不主动重算。丢失的真实成绩只能从备份恢复；补默认值不等于恢复历史进度。

首版支持能够解密、解析且具有可识别 GameStateData 类型头的进度存档；缺失/异常的槽位 ID 可按手动槽位文件名补全。暂不修复系统存档 s.sd、文件截断、加密损坏，也不保证修复所有游戏运行错误。新版本原版字段可能被旧规则视为扩展，使用前核对预览。这个模式会删除其他 MOD 的扩展任务等进度；普通打开和保存不会自动清理。

## 从源码构建

需要 Windows x64、Rust stable、Node.js 18+、MSVC C++ Build Tools 和 Windows SDK。运行工具需要 Microsoft Edge WebView2 Runtime。

在 Visual Studio 开发者 PowerShell 中执行：

```powershell
cd tauri
npm ci
npm --prefix ui ci
npm run build
```

生成的程序位于：

```text
tauri/src-tauri/target/release/SecretFlasherManakaSaveEditor.exe
```

开发模式使用 `npm run dev`。项目另提供根目录的 `build.ps1` 打包脚本，默认查找 Visual Studio 2022 Build Tools 和 Windows SDK 的标准安装位置。

## 项目结构

```text
docs/               字段适用范围与保存时机说明
tauri/
  ui/             TypeScript 界面、样式与多语言名称数据
  src-tauri/      Rust 存档解析、加解密、校验与桌面入口
  metadata.json   字段分类元数据
format_config.json  存档格式配置
build.ps1           本地打包脚本
```
