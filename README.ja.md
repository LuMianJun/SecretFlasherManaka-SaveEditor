# SecretFlasherManaka セーブエディター

**SecretFlasherManaka** 用のWindows向け独立型セーブ編集ツールです。

ゲームの `.sd` ファイルを直接開き、カテゴリー別に内容を確認・編集して、ゲームが使用する暗号化形式で保存できます。MODやBepInExの導入は不要です。セーブデータの処理はすべてローカルで行います。

ダウンロードと更新履歴：[GitHub Releases](https://github.com/LuMianJun/SecretFlasherManaka-SaveEditor/releases)。

## 機能

- RP、成長、ミッション履歴、アイテム、装備、スキル、強化、マップの解放状況、累計記録をカテゴリー別に編集できます。
- 初期表示の「よく使う項目」には、使用可能RP、露出経験値、アイテム、発見許容回数の上限、大人のおもちゃの強化、衣装パーツの強化をまとめています。元のカテゴリーでも同じデータを編集できます。
- 登録済みのアイテム、装備、強化効果などは、選択した表示言語に対応するゲーム本来の名称で表示します。振動モードなどの数値設定も意味を確認して選択できます。
- 原版ミッションの記録は「【マップ】ミッション名」と表示し、マップ名で検索できます。マップ別のドローン記録にも場所を表示します。ドローンの合計回数はマップをまたぐ集計のままです。
- スキルレベルは各スキル本来の上限に合わせて選択できます。数値を直接入力する場合も範囲を確認し、保存済みの範囲外の値を自動で変更することはありません。
- 難易度は原版で選択可能なイージーとオリジナルの2種類です。昼夜は昼または夜として表示します。
- 検索、元に戻す、変更一覧、最後に開いた時点または保存した時点への復元に対応します。
- 外見、プリセット、ショートカット、モード設定、確認済みチュートリアル、一部の詳細記録は初期状態で折りたたみ、必要に応じて展開できます。
- 今回のミッション進捗、未精算の収入、一時状態、マップ内の状態、セーブ一覧の概要、旧私服強化テーブル、補助通知フラグは通常表示しません。カテゴリー件数や検索にも含めません。
- 一部のスキル・強化・衣装の名称表にないIDは通常表示せず、元データは保持します。不明なミッションは表示したまま、セーブに名称がないことを明記します。
- 「元のデータ構造」では未確認の項目も確認・編集でき、オブジェクトやリストの項目を追加・削除できます。
- 保存、名前を付けて保存、セーブスロットIDの検証に対応します。
- 手動スロットの保存時に、同じフォルダーの `s.sd` にある該当スロットのランク、保存日時、難易度、プレイ時間も更新し、ロード一覧に古い値や初期値が残る問題を解消します。
- ロード時の上書き、条件付きの効果、不明な名称など、編集結果に関係する説明を必要に応じて表示します。

**Tauri + Rust + TypeScript + CSS** を使用し、システムのWebView2で動作します。画面と名称データは1つのEXEに組み込まれており、実行にPythonは不要です。

## 表示言語

右上の地球アイコンで、簡体字中国語、繁体字中国語、英語、日本語、韓国語を切り替えられます。原版ゲームと同じ5言語です。言語が未設定の場合は中国語を初期表示とし、各言語の名前で選べるウィンドウを自動で開きます。選択後は設定を記憶し、次回以降は自動表示しません。切り替えても、開いているセーブ、未適用の入力、閲覧状態は保持します。セーブ内のゲーム言語や他の項目は変更しません。

アイテム、スキル、衣装、ミッション、マップ、実績などの名称は原版辞書の該当言語を使用します。ミッションの場所・距離や実績条件は、元のマスターデータと名称の整形規則に従い、中国語から再翻訳しません。一部の古い記録は翻訳キーのない日本語の固定文字列を使用しているため、そのまま表示します。エディター独自の操作、項目説明、修復メッセージは別途翻訳しています。

出典と更新方法は[多言語と原版名称](docs/多语言与原版名称.md)を参照してください。この詳細資料は簡体字中国語です。

## 使い方

`SecretFlasherManakaSaveEditor.exe` を実行し、右上の「セーブを開く」を選択します。開く操作と名前を付けて保存では、初期状態で次のゲームセーブフォルダーを表示します。

```text
%USERPROFILE%\AppData\LocalLow\SheableSoft\SecretFlasherManaka\SaveData
```

項目を選択し、右側で編集して「変更を適用」を押します。この段階ではエディター内のデータだけが変わります。「セーブ」を押すと、現在の項目に未適用の入力がある場合も反映して保存します。

- **セーブ**：ファイル、セーブID、変更件数を確認して現在のファイルを上書きします。
- **名前を付けて保存**：ゲームのセーブフォルダー内で最小の空きスロット番号を提案します。システムセーブの初期名は `s.sd` です。既存ファイルの上書きはファイルダイアログで確認します。成功後は新しい保存先が現在のファイルになります。
- **ショートカット**：`Ctrl+S` で保存、`Ctrl+Shift+S` で名前を付けて保存します。

通常の保存は選択したファイルを上書きし、自動バックアップは作成しません。必要な元のセーブは別途保管してください。

## セーブファイルと保存規則

| ファイル | 内容と検証 |
| --- | --- |
| `0.sd`～`19.sd` | 手動セーブ。内部のスロットIDはファイル名の番号と一致する必要があります。 |
| `s.sd` | 設定、チュートリアル、セーブ一覧を含むシステムセーブ。進行スロットIDは使用しません。 |

`0.sd`～`19.sd` に保存する場合、保存先のファイル名に合わせて内部IDを自動設定します。既存ファイルの上書きでも種類とスロットを検証し、キャンセルや保存失敗では現在の文書のIDは変わりません。20スロットすべてが使用中の場合、名前を付けて保存では現在のファイル名を提案し、保存先と上書きは利用者が選択します。

保存先に `s.sd` がある場合は、該当スロットのロード一覧用概要も更新します。ランクは露出経験値から計算し、難易度とプレイ時間は進行セーブから、保存日時は現在のローカル時刻から取得します。確認画面には同期先を表示し、変更のない文書を再保存して概要を更新することもできます。他のスロット、共通設定、チュートリアルは保持します。独立したコピーの横に `s.sd` がなければ新規作成せず、スロット番号以外のファイル名では概要を同期しません。起動中のゲームが古い概要をキャッシュしている場合は、ゲームを再起動して読み直してください。

元のセーブ構造を保持し、編集範囲だけを置き換えます。未変更の項目、小数精度、元の型情報、不明な内容を維持します。保存時は暗号化と復号の結果を確認し、保存先フォルダーに一時ファイルを書いて検証してから対象を置き換えます。

非表示は削除を意味しません。一時状態の項目もセーブと元データ内に残り、画面に表示されないだけで初期化・削除されることはありません。使用可能RP、累計RP、履歴は別項目で、自動では同期しません。編集した値の組み合わせがゲーム内で意図どおりに動くかは原版の規則に依存します。

原版ミッション名は内蔵の原版名称データを使用します。カスタムミッションの名前は通常セーブに含まれません。名前を推測したり固定で追加したりせず、外部プラグインも要求しません。不明な記録は「不明なミッション（ID …・セーブに名称なし）」と表示します。

項目の適用範囲、ロード時の上書き、保存タイミングは[セーブの種類と項目の動作](docs/存档类型与字段作用.md)を参照してください。この資料は簡体字中国語です。

## セーブ修復（初期対応範囲）

進行セーブを開いて「セーブを修復」を選択し、「拡張データを削除し、必要な元データを補完」の一覧を確認してから「修復を適用」を押します。適用はエディター内のデータだけを変更し、一括で元に戻せます。修復後の初回保存は別ファイルへの保存が必須で、元ファイルは上書きできません。

修復は検証済みの原版項目、列挙値、マスターIDの内蔵ルールを使用します。MODのDLLは読み込まず、MODごとの個別対応も不要です。進行ファイルの拡張項目と、検証済みのアイテム・スキル・ミッション・衣装・プリセット表の拡張記録を削除し、衣装の所持、設定、強化、ロック、すべてのプリセット内の参照もまとめて処理します。原版の旧IDと特殊値は保持し、画面に名称があるかどうかだけでは判定しません。

欠落または構造が異常な元データは、検証済みの初期値で補完します。強化効果3枠、ロックスイッチ4個、衣装・外見プリセット20個などが対象です。有効な数値の元テキストは維持し、既存RP、原版ミッション成績、装備記録を自動再計算しません。失った実際の成績はバックアップからの復元が必要で、初期値の補完は履歴の復元ではありません。

初期実装は、復号・解析が可能で、識別できる `GameStateData` 型ヘッダーを持つ進行セーブに対応します。欠落または不正なスロットIDは手動スロットのファイル名から補完できます。`s.sd`、途中で切れたファイル、暗号化の破損は対象外で、すべてのゲーム内エラーの復旧は保証しません。旧ルールでは新しいゲーム版の項目を拡張と判断する可能性があるため、プレビューを確認してください。この修復は他のMODの追加ミッションなどの進行を削除します。通常の読込・保存では自動で削除しません。

## ソースからのビルド

Windows x64、Rust stable、Node.js 18以上、MSVC C++ Build Tools、Windows SDKが必要です。実行にはMicrosoft Edge WebView2 Runtimeが必要です。

Visual Studio開発者PowerShellで実行します。

```powershell
cd tauri
npm ci
npm --prefix ui ci
npm run build
```

生成されるプログラム：

```text
tauri/src-tauri/target/release/SecretFlasherManakaSaveEditor.exe
```

開発時は `npm run dev` を使用します。ルートの `build.ps1` は、初期状態でVisual Studio 2022 Build ToolsとWindows SDKの標準インストール先を探してパッケージを作成します。
