# SecretFlasherManaka 저장 편집기

**SecretFlasherManaka**용 Windows 독립 실행형 저장 데이터 편집 도구입니다.

게임의 `.sd` 파일을 직접 열어 분류별로 확인하고 수정한 다음, 게임에서 사용하는 암호화 형식으로 저장합니다. MOD나 BepInEx를 설치할 필요가 없으며, 모든 저장 데이터 처리는 로컬에서 이루어집니다.

다운로드 및 업데이트 기록: [GitHub Releases](https://github.com/LuMianJun/SecretFlasherManaka-SaveEditor/releases).

## 기능

- RP, 성장, 미션 기록, 아이템, 장비, 스킬, 강화, 맵 해금 및 누적 통계를 분류별로 편집합니다.
- 처음 표시되는 **자주 쓰는 항목**에는 사용 가능한 RP, 노출 경험치, 아이템, 최대 발각 허용 횟수, 성인용품 강화 및 의상 파츠 강화를 모았습니다. 원래 분류에서도 같은 데이터를 편집할 수 있습니다.
- 등록된 아이템, 장비, 강화 효과 등은 선택한 인터페이스 언어의 게임 원본 명칭으로 표시합니다. 진동 모드 같은 숫자 옵션은 실제 의미를 보고 선택할 수 있습니다.
- 원본 미션 기록은 `【맵】미션명`으로 표시하며 맵 이름으로 검색할 수 있습니다. 맵별 드론 기록에도 장소를 표시하고, 전체 드론 횟수는 여러 맵을 합친 값으로 유지합니다.
- 스킬 레벨은 각 스킬의 원본 최대 레벨에 맞춰 선택합니다. 숫자를 직접 입력해도 범위를 검사하며, 이미 저장된 범위 밖의 값은 자동으로 바꾸지 않습니다.
- 난이도는 원본 게임에서 선택 가능한 이지와 보통 두 가지입니다. 낮과 밤도 해당 상태로 표시합니다.
- 검색, 실행 취소, 변경 목록 및 마지막으로 열거나 저장한 상태로 되돌리기를 지원합니다.
- 외형, 프리셋, 단축 조작, 모드 설정, 확인한 튜토리얼 및 일부 상세 기록은 기본적으로 접혀 있으며 필요할 때 펼칠 수 있습니다.
- 현재 미션 진행도, 정산 대기 수익, 일시적 상태, 맵 현장 데이터, 슬롯 목록 요약, 구형 사복 강화 표 및 보조 알림 표시는 기본 화면에서 숨깁니다. 분류별 개수와 검색에도 포함하지 않습니다.
- 일부 스킬·강화·의상 명칭 표에 없는 ID는 숨기되 원본 데이터는 유지합니다. 알 수 없는 미션 기록은 계속 표시하고, 저장 파일에 이름이 없음을 명시합니다.
- **원본 데이터 구조**에서는 알 수 없는 필드도 확인·편집하고, 객체나 목록의 항목을 추가·삭제할 수 있습니다.
- 저장, 다른 이름으로 저장 및 저장 슬롯 ID 검사를 지원합니다.
- 수동 슬롯 저장 시 같은 폴더의 `s.sd`에서 해당 슬롯의 랭크, 저장 시각, 난이도 및 플레이 시간을 갱신하여 불러오기 목록에 예전 값이나 기본값이 남는 문제를 해결합니다.
- 불러올 때 덮어쓰는 값, 조건부 효과, 확인할 수 없는 명칭 등 편집 결과에 영향을 주는 설명을 필요에 따라 표시합니다.

**Tauri + Rust + TypeScript + CSS**로 만들었으며 시스템의 WebView2를 사용합니다. 인터페이스와 명칭 데이터는 하나의 EXE에 포함되어 있어 실행에 Python이 필요하지 않습니다.

## 인터페이스 언어

오른쪽 위의 지구본 버튼으로 중국어 간체, 중국어 번체, 영어, 일본어, 한국어를 전환합니다. 원본 게임과 같은 다섯 가지 언어입니다. 언어 설정이 없으면 기본 화면은 중국어이며, 각 언어의 고유 이름을 표시하는 선택 창을 자동으로 엽니다. 직접 선택한 뒤에는 설정을 기억하고 다음 실행부터 자동으로 묻지 않습니다. 언어를 전환해도 열린 저장 파일, 아직 적용하지 않은 입력 및 탐색 상태는 유지합니다. 저장 파일 안의 게임 언어나 다른 필드는 바꾸지 않습니다.

아이템, 스킬, 의상, 미션, 맵, 업적 등의 명칭은 원본 게임 사전의 해당 언어 열을 사용합니다. 미션 장소·거리와 업적 조건은 원본 마스터 데이터 및 이름 형식 규칙에 따라 넣으며 중국어에서 다시 번역하지 않습니다. 일부 구형 기록은 번역 키가 없는 일본어 고정 문자열이므로 원문을 유지합니다. 편집기 자체의 조작, 필드 설명 및 복구 안내는 별도로 번역합니다.

출처 및 갱신 방법은 [다국어와 원본 명칭](docs/多语言与原版名称.md)을 참고하세요. 이 상세 문서는 중국어 간체입니다.

## 사용 방법

`SecretFlasherManakaSaveEditor.exe`를 실행하고 오른쪽 위의 **저장 열기**를 누르세요. 열기와 다른 이름으로 저장은 기본적으로 게임 저장 폴더를 엽니다.

```text
%USERPROFILE%\AppData\LocalLow\SheableSoft\SecretFlasherManaka\SaveData
```

필드를 선택하고 오른쪽에서 편집한 뒤 **변경 적용**을 누르세요. 이 단계에서는 편집기 내부 데이터만 바뀝니다. **세이브**를 누르면 현재 필드에서 아직 적용하지 않은 입력도 반영하여 저장합니다.

- **세이브**: 파일, 저장 ID 및 변경 개수를 확인한 후 현재 파일을 덮어씁니다.
- **다른 이름으로 저장**: 게임 저장 폴더에서 사용하지 않는 가장 작은 슬롯 번호를 제안합니다. 시스템 저장의 기본 이름은 `s.sd`입니다. 기존 파일 덮어쓰기는 파일 대화상자에서 확인합니다. 성공하면 새 위치가 현재 파일이 됩니다.
- **단축키**: `Ctrl+S`로 저장, `Ctrl+Shift+S`로 다른 이름으로 저장합니다.

일반 저장은 선택한 파일을 덮어쓰며 자동 백업을 만들지 않습니다. 보관할 원본 저장은 별도로 복사해 두세요.

## 저장 파일 및 저장 규칙

| 파일 | 내용 및 검사 |
| --- | --- |
| `0.sd`~`19.sd` | 수동 저장. 내부 슬롯 ID는 파일명의 번호와 일치해야 합니다. |
| `s.sd` | 설정, 튜토리얼 및 저장 목록을 포함하는 시스템 저장. 진행 슬롯 ID는 사용하지 않습니다. |

`0.sd`~`19.sd`로 저장하면 대상 파일명에 맞춰 내부 슬롯 ID를 자동 설정합니다. 기존 파일을 덮어쓸 때도 저장 형식과 슬롯을 검사하며, 취소하거나 저장에 실패해도 현재 문서의 슬롯 ID는 바뀌지 않습니다. 20개 슬롯이 모두 사용 중이면 다른 이름으로 저장에서 현재 파일명을 제안하므로, 저장 위치와 덮어쓰기는 직접 선택해야 합니다.

대상 폴더에 `s.sd`가 있으면 해당 슬롯의 불러오기 목록 요약도 갱신합니다. 랭크는 노출 경험치로 계산하며, 난이도와 플레이 시간은 진행 저장에서, 저장 시각은 현재 로컬 시간에서 가져옵니다. 확인 창에 동기화 대상을 표시하며 변경 없는 문서를 다시 저장해서 요약을 갱신할 수도 있습니다. 다른 슬롯, 공통 설정 및 튜토리얼 기록은 유지합니다. 독립된 사본 옆에 `s.sd`가 없으면 새로 만들지 않고, 슬롯 번호가 아닌 파일명에는 요약 동기화를 적용하지 않습니다. 실행 중인 게임이 예전 요약을 메모리에 보관하고 있다면 게임을 재시작하여 다시 읽으세요.

원본 저장 구조를 유지하고 편집한 범위만 교체합니다. 바꾸지 않은 필드, 소수 정밀도, 원본 형식 정보 및 알 수 없는 내용을 보존합니다. 저장 시 암호화·복호화 결과를 검사하고, 대상 폴더에 임시 파일을 기록하여 검증한 다음 대상 파일을 교체합니다.

숨김은 삭제가 아닙니다. 실행 중 상태 필드도 저장 파일과 원본 조각에 남으며 화면에 보이지 않는다는 이유로 초기화하거나 제거하지 않습니다. 사용 가능한 RP, 누적 RP 및 과거 기록은 별도 필드이며 자동으로 동기화하지 않습니다. 편집한 값의 조합이 게임 내에서 의도대로 동작하는지는 원본 게임 규칙에 달려 있습니다.

원본 미션명은 도구에 포함된 원본 명칭 데이터에서 가져옵니다. 사용자 정의 미션명은 대개 저장 파일에 없습니다. 도구는 이름을 추측하거나 고정값으로 넣지 않으며 외부 플러그인도 요구하지 않습니다. 인식할 수 없으면 “알 수 없는 미션 (ID …, 저장 파일에 이름 없음)”으로 표시합니다.

필드별 적용 범위, 불러올 때 덮어쓰는 동작 및 저장 시점은 [저장 형식과 필드 동작](docs/存档类型与字段作用.md)을 참고하세요. 이 상세 문서는 중국어 간체입니다.

## 저장 복구 — 초기 지원 범위

진행 저장을 열고 **저장 데이터 복구**를 누르세요. “모드 데이터 제거 및 필수 원본 데이터 보완” 목록을 확인한 뒤 **복구 적용**을 선택합니다. 적용은 편집기 내부 데이터만 바꾸며 한 번에 취소할 수 있습니다. 복구 후 처음 저장할 때는 다른 파일에 저장해야 하며 원본을 덮어쓸 수 없습니다.

복구는 현재 검증된 원본 필드, 열거값 및 마스터 ID의 내장 규칙을 사용합니다. MOD DLL을 읽지 않으며 MOD마다 개별 지원을 추가할 필요도 없습니다. 진행 파일의 확장 필드와 검증된 아이템·스킬·미션·의상·프리셋 표의 확장 기록을 제거합니다. 의상 보유, 옵션, 강화, 잠금 및 모든 프리셋의 관련 참조도 함께 처리합니다. 원본의 구형 ID와 특수 값은 유지하며, 인터페이스에 이름이 있는지만으로 유효성을 판단하지 않습니다.

누락되거나 구조가 잘못된 원본 데이터는 검증된 기본값으로 채웁니다. 강화 효과 슬롯 3개, 잠금 스위치 4개, 의상·외형 프리셋 20개 등이 포함됩니다. 유효한 숫자의 원본 텍스트는 보존하며, 기존 RP, 원본 미션 성적 및 장비 기록을 자동 재계산하지 않습니다. 잃어버린 실제 성적은 백업에서 복원해야 하며, 기본값 보완은 과거 진행도 복원이 아닙니다.

초기 구현은 복호화·분석이 가능하고 식별 가능한 `GameStateData` 형식 헤더가 있는 진행 저장을 지원합니다. 누락되거나 잘못된 슬롯 ID는 수동 슬롯 파일명에 맞춰 채울 수 있습니다. 시스템 저장 `s.sd`, 잘린 파일 또는 손상된 암호화는 복구하지 않으며 모든 게임 실행 오류의 해결을 보장하지 않습니다. 이전 규칙이 새 게임 버전의 필드를 확장으로 판단할 수 있으므로 미리보기를 확인하세요. 이 모드는 다른 MOD의 추가 미션 등 확장 진행도를 삭제합니다. 일반 열기와 저장은 이 정리를 자동 수행하지 않습니다.

## 소스에서 빌드

Windows x64, Rust stable, Node.js 18 이상, MSVC C++ Build Tools 및 Windows SDK가 필요합니다. 실행에는 Microsoft Edge WebView2 Runtime이 필요합니다.

Visual Studio 개발자 PowerShell에서 실행하세요.

```powershell
cd tauri
npm ci
npm --prefix ui ci
npm run build
```

실행 파일 생성 위치:

```text
tauri/src-tauri/target/release/SecretFlasherManakaSaveEditor.exe
```

개발 모드는 `npm run dev`를 사용합니다. 루트의 `build.ps1` 패키징 스크립트는 기본적으로 Visual Studio 2022 Build Tools와 Windows SDK의 표준 설치 위치를 찾습니다.
