# 存档字段的适用范围与保存时机

核查日期：2026-10-11。适用于当前工作区所逆向的 SecretFlasherManaka 原版程序。

依据原始程序的反汇编与 ISIL、恢复后的读写代码，以及已有的手动存档、系统存档和槽位备份明文。未修改实际存档；不同游戏版本或插件可能有不同的保存入口。

## 文件与适用范围

| 文件 | 内容 | 使用方式 |
| --- | --- | --- |
| `SaveData/0.sd`～`19.sd` | 对应槽位的游戏进度、角色外观 | 选择槽位读档；手动保存和部分游戏流程都会写当前槽位。 |
| `SaveDataBackup/0.sd`～`19.sd` | 对应槽位的进度备份 | 返回公寓后的延迟保存目标，与正常槽位共用数据结构。 |
| `SaveData/s.sd` | 全局设置、教程、存档列表摘要 | 读取进度前先读取；改设置和保存进度都会写入。 |

编辑器按内容区分系统数据与进度数据。保存到 `0.sd`～`19.sd` 时，工具按目标文件名设置内部槽位 ID，并保留类型、编号范围和覆盖目标校验；取消或保存失败不改变当前文档的槽位 ID。其他名称可以用于另存副本，保留原有内部槽位 ID，名称本身不会让游戏增加新的读档入口。

另存为默认定位到游戏存档目录。进度存档预设为 `0.sd`～`19.sd` 中最小的未占用编号；全部占用时保留当前文件名，仍需正常确认覆盖。系统存档预设为 `s.sd`。

## 顶层字段

| 字段 | 适用范围 | 作用和修改边界 |
| --- | --- | --- |
| `GameStateData` | 进度存档 | 游戏状态与进度，原版有 107 个序列化字段。整体加载后再进行兼容补齐与初始化。 |
| `PlayerCustomData` | 进度存档 | 角色外观；身高为初始化标记值时恢复默认脸型与身体，缺失的发型自定义记录会补默认值。 |
| `SaveDataSlotIndex` | 进度存档 | 进度所属手动槽位的编号；界面隐藏，由保存目标统一管理。 |
| `IsTrial` | 进度存档 | 试玩版列表据此限制读取正式版存档；进入游戏后，试玩状态以运行程序版本重新赋值。界面隐藏，保留原始值。 |
| `OptionData` | 系统存档 | 全局设置，全部槽位共用。在进度文件添加同名键不会替代系统设置。 |
| `TutorialData` | 系统存档 | 全局教程和提示记录，各进度槽位共用；默认收起，不代表任务或地图解锁进度。 |
| `ManualSaveTime` | 系统存档，仅列表显示 | 20 个手动槽位的显示时间；保存对应槽位时更新，修改时间不会创建存档。界面隐藏。 |
| `RankData` | 系统存档，仅列表显示 | 各槽位的等级摘要；实际等级根据进度中的露出经验判定。界面隐藏。 |
| `DifficultData` | 系统存档，仅列表显示 | 各槽位的难度摘要；实际难度来自进度中的 `DifficultType`。界面隐藏。 |
| `TotalPlayTimeData` | 系统存档，仅列表显示 | 各槽位的游玩时间摘要；实际统计来自进度中的 `StatistisTotalPlayTime`。界面隐藏。 |

保存进度会先写系统数据，再写进度文件。系统摘要可能被下一次游戏保存重新生成；编辑器保存一个文件不会自动改写另一个文件的摘要。

## 读档和初始化会影响的字段

| 字段 | 适用范围 | 原版行为 |
| --- | --- | --- |
| `CurrentStageType` | 进度存档 | 读档后无条件置为公寓，不能修改它来恢复外出地图。 |
| `ActiveDroneMissionId` | 进度存档 | 读档后置为未接取；历史完成记录由其他字段保存。 |
| `ActiveDroneProgress` | 进度存档 | 读档后清零，不恢复正在进行的无人机任务。 |
| `PlayerMental` | 进度存档 | 先读取存档值，正常进入公寓的初始化回调再恢复到当前精神上限。 |
| `PlayerPosition`、`PlayerRotation` | 进度存档 | 场景一致时恢复位置和朝向；读档场景已改为公寓，不能组合它们恢复外出现场。 |
| `OptionData.MissionPanel` | 系统存档 | 先从系统存档读取，加载进度时又强制开启任务面板。 |
| `ItemDict[10000]`、`ItemDict[10001]` | 进度存档 | 拥有对应道具而缺遥控器时，读档补一个；删除遥控器可能被补回。 |
| `PlayerEcstasy` | 进度存档 | 原版保存进度时将不低于 0.99 的值限制到 0.99，编辑器不会主动执行这个运行时限幅。 |

## 数值相近但用途不同的字段

| 字段 | 适用范围 | 实际用途 |
| --- | --- | --- |
| `CurrentRp` | 进度存档 | 当前可消费 RP；修改一个槽位不会同步其他槽位。 |
| `ExposeExp` | 进度存档 | 露出经验，参与等级判定；与可用 RP、累计获得 RP、系统列表等级分别保存。 |
| `DifficultType` | 进度存档 | 实际游戏难度；原版界面开放简单（1）与普通（2），编辑器提供这两档。修改系统列表摘要不会替代本字段。 |
| `StatistisTotalPlayTime` | 进度存档 | 实际累计游玩时间；保存该槽位时用于更新系统列表摘要。 |

`IsDaytime` 的字段名显示为“昼夜时间”，取值分别显示“白天”和“夜晚”。难度枚举中的休闲（0）仍存在于原版代码，但原版难度选择预制体的对应按钮未启用，不能据此视为玩家可选的第三档。

其余原版 GameStateData 字段的文件级适用性通过整体序列化和加载确认。这不表示每个嵌套成员均已逐项验证运行效果，也不保证字段组合合法。未知顶层键、未知 GameStateData 字段保留编辑能力。界面说明按需提供具体注意事项，不为每个普通字段重复说明所属存档类型；有读档覆盖、生效条件或名称未知等实际修改边界时才显示相应提示。角色外观的初始化限制只在选中整个外观分组时说明，不重复到每个子字段。

## 界面展示范围

普通分类保留资源、成长、所有权、强化、长期任务成绩、历史统计和场景解锁。最大被发现容忍次数放在技能与强化中；发型所有权放在物品与装备中。

打开进度存档默认进入“常用”，展示 `CurrentRp`、`ExposeExp`、`ItemDict`、`PlayerMaxLife`、`AdultGoodsReinforceEffectDict` 和 `CosplayPartsReinforceEffectDict` 六项。原分类仍可编辑同一份数据，常用页不另存一份副本；旧私服强化表不在常用页展示。

默认隐藏 49 个 GameStateData 字段及任务面板开关、顶层试玩标记和槽位编号：当前场景、外出待结算收益、本次任务与无人机进度及收益、即时身体状态、当前生命、手持物、手铐交互状态与计时、药品临时效果、衣物动作状态、坐标、NPC 和掉落物现场数据、洗衣机编号及疑似遗留辅助记录。系统槽位列表摘要、首次成人内容提问标记及试玩结束教程标记也隐藏。隐藏规则只匹配对应存档路径，不因字段同名而隐藏其他插件或预设中的内容。

技能等级、被动技能、服饰强化与服饰等字典中，原版名称表无法识别的编号也不在普通列表展示；这按编号是否有已知名称判断，不按当前数值是否为零判断。原版任务之外的未知任务记录继续展示，提示“未知任务（编号…，存档未记录名称）”。原版任务名使用内置原版名称数据，自定义任务名不写死，也不依赖外部代码或插件。

历史统计中的 `StatistisMaxNudeMoveDistance` 与 `StatistisMaxEarnRpByOneDay` 暂时隐藏：恢复源码未见业务引用，当前原始 ISIL 核查也尚未确认相应读写，不能据此断言所有版本均无用途。`StatistisMissionAchiveCount` 由结算流程累加，继续保留，即使当前值为零。`StatistisTotalLostExp` 确实由失败处理累计，但当前未见它作为等级、奖励或统计面板的输入，按修改用途隐藏，原数据保留。不能仅凭零值判断字段无效。

`ReleasedInfoRank`、`ConfirmedReleasedInfoRank` 与 `ConfirmedReinforceRank` 是解锁内容及强化提示的辅助记录，不是实际等级或强化效果，默认隐藏。`AnsweredFirstSexOption` 只决定新游戏前是否弹出首次成人内容设置；`TutorialData.IsOpenEndTryal` 只用于试玩结束教程，均不作为正式版进度入口展示。

`TutorialData.IsOpenSecondMap` 也隐藏。它实际对应快速移动教程，不是地图解锁标记；原版未开放该教程入口，预制体中的对应分类按钮未启用，教程初始化也不主动开启这个按钮，当前原始调用中未见触发该教程类型。

外套所有权 `ClothesDict` 与当前外套 `PlayerCurrentClothes` 按编辑用途隐藏。当前核查版本正常可用的外穿衣物只有外套；连帽衫虽有枚举和资源，实际衣物模型选择仅处理外套与裸身，不能将资源存在视为已开放功能。旧私服所有权与装备状态 `PlayerCostumeDict` 也隐藏：当前商店的服饰分类与背包使用服饰部件系统 `PlayerCosplayPartsDict`，背包的旧私服类别没有正常入口。旧所有权与装备表仍有残留读写，保留原始记录，不清空或迁移到部件表。

旧私服强化表 `CostumeReinforceEffectDict` 隐藏。已核查原版 `PlayerReinforceEffectManager.Apply` 汇总成人玩具与服饰部件强化，不读取这张旧表，不能将旧私服强化记录视为当前生效的强化效果。隐藏只影响展示，原始记录仍保留。

遥控器等级 `VibeRemoconLevel` 控制振动模式切换的循环范围，原版确实读取；当前版本新建存档默认设为 3，已开放关、弱、强、随机四种模式，按修改用途隐藏。隐藏不改变原有等级，也不替旧存档自动升级。

“性癖类型” `CurrentSexualityType` 也隐藏。当前版本仅确认构造时赋默认值、遗留选择面板读取及应用选择后写回；原版菜单入口未启用，未见任务、RP 或 NPC 等实际玩法读取。该字段与 `IsActiveFutanari` 独立，不能据此推断后者也没有作用。

角色外观、预设、服饰部件选项、快捷操作、模式设置、被动技能开关及强化锁定状态默认收起。教程已读记录和无人机分场景历史明细也默认收起；这些明细有实际消费者，不因与总记录相近而判为无效。搜索仍可找到收起的内容，但不包含隐藏字段；没有可展示字段的分类不显示。

部分外观参数按自身生效条件展示：当前外观只在启用 `IsActiveFutanari` 时展示对应属性；肤色色板与 RGB 随自由肤色开关切换；左眼独立图案只在异色瞳开启时展示。外观方案 `LoadoutCustomizeDatas` 使用方案自己的 `CustomizeIsSkinColorFree` 和 `CustomizeOddEye` 判断；方案没有角色模式开关，因此不使用当前角色的模式过滤方案属性。

已知服饰部件的颜色、材质、部件开关及隐藏参数按原版部件能力显示；某部件不提供的参数不在普通列表展示。未知部件没有可靠的能力记录，保留原字段，不按缺失记录推断它不支持某个参数。

隐藏只影响列表、搜索和条目计数，不删除或重置数据。加载后的完整数据及原始片段仍保留全部字段，保存沿用原有的局部替换逻辑。

有些隐藏字段确实会在读档后使用。例如 MissionSatisfyDict 会在任务初始化时读取，地图手铐标志也存在初始化处理；隐藏依据是普通玩家的修改用途，而非统一认定它们无效。两张 ContinueMission 表、洗衣机编号和无人机充电标志的当前实际恢复用途仍未完全确认。

## 保存时机

回到公寓后，切场景完成回调处理定时手铐、按需打开结算面板、重置任务，再安排 **5 秒非缩放时间延迟**。延迟回调确认 InGameManager 仍有效后，保存到 `SaveDataBackup/当前槽位.sd`，并更新系统存档中的槽位摘要。

结算面板第一阶段动画完成时，另行保存到正常的 `SaveData/当前槽位.sd`。两条调用分别存在，不能合并理解为同一次保存。

衣柜中的手动保存、部分失败处理和紧急脱出等流程也会保存当前槽位。设置菜单关闭等操作写系统存档。编辑器自身只在点击“保存”或“另存为”并完成相应确认后写文件。

## 技能等级范围

当前原版活动技能表的 40 个技能以各自 `MaxLevel` 为上限：慢动作 0～5，服装装备上限提升 0～3，其余 38 项 0～1。0 表示未学习升级，仍可能保留基础效果；被动开关与等级分别保存。范围数据随工具内置，不依赖外部插件。

普通技能编辑使用合法等级下拉，直接修改该技能原始数值时也检查整数和范围。已有异常值会显示，但不因打开存档或编辑其他字段自动改写。原版购买界面限制上限，底层加级与读档补齐不校正既有越界值；完整原始结构保留显式编辑片段的能力。
