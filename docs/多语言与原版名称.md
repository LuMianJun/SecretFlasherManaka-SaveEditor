# 五语言与原版名称

编辑器支持原游戏字典中的 `sc`、`tc`、`en`、`ja`、`ko` 五列。界面语言保存在本机 `secretflashermanaka-save-editor.locale` 中，不写入 `.sd`，也不会更改 `OptionData.Language`。首次使用默认简体中文，并弹出带原生语言名称的选择窗口；启动本身不会自动保存默认语言，只有明确选择后才记住设置。右上角地球图标可以随时重新选择。

`tauri/ui/src/data/messages.json` 保存编辑器操作、数据说明、错误提示和少量原版通用词语；`game-locales.json` 保存实际使用的原版名称、对应语言键、参数和字典文件 SHA256。名称显示不改变存档中的数字编号、字段路径或可选数值。

主表中的 `NameKey` 优先于中文文本匹配。同名中文可能有不同的英语或韩语含义，例如服饰部件的 Blindfold 与成人玩具的 Eye Mask，以及衣装系列 Jumpsuit 与部件 Leotard。任务按 `StageType * 10000 + index` 识别，并遵循 `MMissionOverrideRecord.GetMissionName` 的区域或数值参数；成就的分数、场景和百分比也按主表填入。

少量旧版或调试记录在原版资源里就是日文常量、没有字典项。编辑器保留原文字面名称，不将人工译名冒充原版翻译。界面上的修复说明及字段功能说明属于编辑器文案。

## 更新名称数据

通常构建只使用仓库内的 JSON，无需游戏文件、Unity 工程、Python 或翻译服务。需要从已有合法本地原版资源更新名称时，安装开发依赖 PyYAML，并运行：

```text
python tools/generate-game-locales.py --dictionary <dictionary.txt> --assets <Assets/MonoBehaviour> --repo . --output <existing-audit-directory>
```

审阅生成的 `game-locales.json` 后替换 `tauri/ui/src/data/game-locales.json`。同目录的 `game-text.json` 与 `pending.json` 只用于核对；编辑器文案直接维护 `messages.json`。游戏对白与未使用文本不随编辑器分发。

## 验证

`npm --prefix tauri/ui test` 检查五列完整性、模板参数一致性、原版名称键和格式化结果、相同中文对应不同名词的情况，以及编号、选项与原始数值不随语言变化。原生窗口检查另行验证即时切换、未暂存输入、搜索、重开后的语言选择，以及各语言下的修复预览和另存保护。

2026-10-26 已完成 44 项既有界面检查、6 项五语言专项检查、27 项 Rust 回归检查和 9 项原生窗口检查。原生检查覆盖五语言任务搜索、未暂存数值不丢失、语言重载保留、最小窗口宽度及五语言下的修复预览、取消、源文件保护、另存和再次扫描；测试只写临时副本。
